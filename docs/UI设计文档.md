## 1. 设计目标与原则

### 1.1 品牌关键词

**轻、暖、快、果冻感。**

- **轻**：奶油底色、白卡片、少阴影，不压迫。
- **暖**：橙、柠檬、莓果色，像一盘切好的水果。
- **快**：大按钮、短路径、倒计时一眼可见。
- **果冻感**：圆润、微弹、按压有反馈，但不幼稚。

避免：电竞黑、荧光绿、赛博紫、过度拟物、满屏粒子。

### 1.2 体验目标

| 目标 | 视觉/交互落点 |
|---|---|
| 3 次点击内创建或加入 | 首页两个大按钮；加入页自动提交 |
| 答题 1 次点击完成 | 选项整卡可点，点击即提交，无需确认 |
| 状态 1 秒内可见 | 选中、已提交、✓/✗、离线都有明确视觉 |
| 结算一屏看懂 | 领奖台 + 完整排名 + 我的数据，不藏在二级页 |
| 失败有出路 | 每个错误态都有「重试/返回/回对局」 |
| 低端机不卡 | 动效可降级，列表不一次性渲染 50 行以上 |

### 1.3 设计原则

1. **一屏一个主任务**：首页是「建房/加入」，等待页是「开始」，对局页是「选一个」，结算页是「再来一局」。
2. **拇指优先**：主操作固定在底部安全区上方；顶部只放信息与返回。
3. **状态必须可见**：玩家不需要猜「我提交了吗」「他答了吗」「现在能不能点」。
4. **轻反馈**：按压 120ms，选中 160ms，揭晓 240ms；不阻塞下一次操作。
5. **不惩罚用户**：按钮禁用时在附近解释原因，不用「点不了」的死路。
6. **颜色不是唯一信息**：正确/错误同时有 ✓/✗ 与文字；选项字母与颜色只是辅助。
7. **可降级**：低端机、减少动态效果、字体放大时，布局仍可用。

### 1.4 明确不做

- 不做深色模式（P2）；首版只有浅色。
- 不做横屏、平板双栏。
- 不引入第三方 UI 库的默认视觉。
- 不用大面积渐变、玻璃拟态、复杂插画。
- 不在同一屏放两个以上主按钮。
- 不用连续弹窗打断答题。

#### 选项字母色

四个字母色只用于**徽标、描边、浅底**，不用于表达对错；正确/错误始终用语义色 + 图标。

| 选项 | Accent | Soft | Ink |
|---|---|---|---|
| A | `#4E8CFF` | `#EAF1FF` | `#2F5FD0` |
| B | `#2FBF71` | `#E8F8EF` | `#1C7C46` |
| C | `#F5A623` | `#FFF6E5` | `#9A6200` |
| D | `#8B5CF6` | `#F1ECFF` | `#5B3DBD` |

#### 用色规则

1. `--color-primary` 只做大面积填充/描边；小字用 `--color-primary-ink`。
2. 主按钮**不使用白字**；白字在亮橙上对比度不足。
3. 正确/错误不能只靠红绿；必须有 ✓/✗ 和「正确/你的选择」。
4. 一屏内除选项字母色外，不超过 3 个语义色（主色 + 成功/危险）。
5. 浅色底上的正文对比度 ≥ 4.5:1；大号标题 ≥ 3:1。
6. 禁用态可以降低对比度，但文字仍需可读（约 3:1）。

### 2.2 字体系统

#### 字体栈

```css
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC",
  "Helvetica Neue", "Microsoft YaHei", sans-serif;
```

不加载 Web Font；数字使用 `font-variant-numeric: tabular-nums`，避免倒计时/分数跳动。

#### 字号与行高

| Token | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| `display` | 56/64rpx | 700 | 首页 slogan、结算冠军分 |
| `h1` | 44/56rpx | 600 | 页面主标题 |
| `h2` | 36/48rpx | 600 | 题干、区块标题 |
| `h3` | 32/44rpx | 600 | 卡片标题、按钮文字 |
| `body` | 30/46rpx | 400 | 正文、选项 |
| `body-sm` | 26/40rpx | 400 | 辅助说明、列表副标题 |
| `caption` | 24/36rpx | 400 | 标签、时间、提示 |
| `micro` | 22/32rpx | 400 | 版本号、脚注 |
| `number-xl` | 64/64rpx | 700 | 房间码、我的名次 |
| `number-lg` | 44/48rpx | 700 | 总分、倒计时 |
| `number-md` | 32/40rpx | 700 | 排名分、按钮内数字 |

#### 排版规则

- 题干最多 3 行；选项最多 2 行；标题最多 2 行；按钮文字 1 行。
- 超出用省略号；揭晓时可展开完整选项（P1）。
- 中文段落行高不低于 1.5；题干 1.5；按钮 1.35。
- 标题字重 600，正文 400；不要用 800/900，避免厚重。
- 数字用 tabular-nums；分数变化时只改数字，不改变布局宽度。
- 英文/数字与中文之间不强制加空格；房间码每 3 位可用 8rpx 字距。

### 2.4 圆角、描边与阴影

| Token | 值 | 用途 |
|---|---|---|
| `--radius-xs` | 12rpx | 小标签、提示条 |
| `--radius-sm` | 16rpx | 小卡片、Toast |
| `--radius-md` | 20rpx | 输入框、代码格 |
| `--radius-lg` | 24rpx | 次级卡片 |
| `--radius-xl` | 32rpx | 主卡片、弹窗 |
| `--radius-2xl` | 40rpx | 底部弹层顶部 |
| `--radius-pill` | 999rpx | 按钮、标签、开关 |

- 描边统一 2rpx；选中态不改变边框宽度，避免布局跳动，用底色 + 描边颜色区分。
- 卡片阴影：`0 8rpx 24rpx rgba(122, 63, 32, 0.08)`。
- 浮层阴影：`0 16rpx 40rpx rgba(122, 63, 32, 0.14)`。
- 主按钮阴影：`0 12rpx 28rpx rgba(255, 122, 69, 0.28)`；次按钮无阴影。
- 不使用内阴影、发光、彩色多重阴影。

### 2.5 图标与插画

- 图标风格：2rpx 线性、圆角端点、24×24 网格；填充图标只用于 TabBar 选中态。
- 尺寸：16/20/24/28/32px 对应 32/40/48/56/64rpx。
- 首版允许 emoji 过渡（🏆 ⏱️ 🔗 📤 🍎），但必须统一字号与基线；P1 换线性图标。
- 插画：首版用 emoji + CSS 色块，不引入大图；空状态可用 1 个 96rpx emoji。
- 分享封面：500×400px，5:4，品牌底 + 大标题 + 3 个水果 emoji，≤ 200KB。
- 禁止：彩色渐变图标、3D 图标、带文字的小图标。

### 2.7 动效

| 场景 | 时长 | 缓动 | 说明 |
|---|---|---|---|
| 按钮按压 | 120ms | ease-out | 缩放 0.98 + 下移 2rpx |
| 选项选中 | 160ms | ease-out | 底色/描边渐变 |
| 倒计时每秒 | 1000ms | ease-in-out | 数字回弹；最后 5 秒红色脉冲 |
| 揭晓正确/错误 | 240ms | ease-out | 卡片高亮 + ✓/✗ 弹入 |
| 分数变化 | 400ms | ease-out | 数字滚动，不粒子 |
| 领奖台 | 400ms | ease-out | 从下向上，间隔 80ms |
| Toast | 150ms 进 / 150ms 出 | ease-out | 不遮挡主操作 |
| 弹窗 | 200ms | ease-out | 遮罩淡入 + 卡片上浮 |
| 页面切换 | 系统默认 | — | 不自定义转场 |

- 只在 `transform` / `opacity` 上做动画；不改宽高。
- 低端机或系统「减少动态效果」时：关闭脉冲、领奖台动画、数字滚动，保留颜色变化。
- 倒计时数字每秒变化一次，环形进度可 250ms 更新一次。

## 3. 按钮系统

按钮是这套 UI 里最重要的交互元件。目标：**一眼知道主操作、按下去有反馈、不能点时知道为什么**。

### 3.1 按钮家族

| 类型 | 使用场景 | 一屏数量 | 视觉权重 |
|---|---|---|---|
| Primary 主按钮 | 创建、加入、开始、再来一局 | 1 | 最高 |
| Secondary 次按钮 | 加入房间、邀请好友、取消 | ≤ 2 | 中 |
| Ghost 幽灵按钮 | 弹窗取消、次级返回 | ≤ 2 | 低 |
| Text 文字按钮 | 复制、编辑、榜单规则、返回首页 | 不限 | 最低 |
| Danger Soft 危险按钮 | 离开房间、退出对局 | 1 | 中高 |
| Small 小按钮 | 复制房间码、分享、编辑资料 | 不限 | 低 |
| Icon 图标按钮 | 返回、关闭、分享 | 1–2 | 低 |

原则：

- 一屏只允许一个 Primary。
- 破坏性操作不用 Primary 的橙色，也不使用高饱和红底白字；用 Danger Soft。
- 同一区域最多两个按钮并排；超过两个改为纵向排列。
- 文字按钮的点击热区必须 ≥ 88rpx，即使视觉只有 32rpx 高。

### 3.2 按钮结构与尺寸

```text
┌──────────────────────────────────┐
│  [＋]    创建房间           [→]  │  96rpx
└──────────────────────────────────┘
  40rpx    32/600           40rpx
```

| 尺寸 | 高度 | 左右内边距 | 字号 | 圆角 | 用途 |
|---|---|---|---|---|---|
| Large | 96rpx | 40rpx | 32rpx | 999rpx | 底部主操作 |
| Medium | 80rpx | 32rpx | 30rpx | 999rpx | 卡片内操作 |
| Small | 64rpx | 24rpx | 28rpx | 999rpx | 复制/分享/编辑 |
| Icon | 72×72rpx | — | 40rpx 图标 | 50% | 返回/关闭/分享 |

- 底部主按钮宽度 = 内容宽 686rpx。
- 行内按钮最小宽度 200rpx；文字按钮不设最小宽度，但热区补足。
- 图标与文字间距 12rpx；图标 36rpx。
- 按钮文字单行，超出省略；不使用两行按钮。
- 按钮内不换行、不缩进、不加句号。

### 3.3 主按钮 Primary

**用途**：创建房间、加入、开始游戏、再来一局、保存资料。

| Disabled | `#F6D9CC` | `#8A6A5C` | 无 | 禁止点击 |

### 3.4 次按钮 Secondary

**用途**：首页「加入房间」、等待页「邀请好友」、弹窗「取消」。

| 状态 | 背景 | 文字 | 描边 | 阴影 |

| Default | `#FFFFFF` | `#B7410E` | `2rpx solid #FFD3BF` | 无 |
| Pressed | `#FFF0E6` | `#B7410E` | `2rpx solid #FF7A45` | 无 |
| Loading | `#FFFFFF` | `#B7410E` + spinner | 同 Default | 无 |
| Disabled | `#FFFDF9` | `#B9A79D` | `2rpx solid #F0E4D8` | 无 |

```css

  height: 88rpx;
  padding: 0 32rpx;
```

- 次按钮高度 88rpx，视觉上略低于主按钮，形成层级。
- 不使用阴影；描边已经足够。
- 同一屏最多两个次按钮，且不要与主按钮等宽并排（会抢焦点）。

### 3.5 幽灵、文字、危险与小按钮

#### Ghost 幽灵按钮

用于弹窗取消、次级返回。

| 状态 | 背景 | 文字 |
|---|---|---|
| Default | 透明 | `#6F6259` |
| Pressed | `rgba(45,42,38,0.05)` | `#2D2A26` |
| Disabled | 透明 | `#B9A79D` |

高度 80rpx，字号 30rpx，圆角 999rpx，无描边。

#### Text 文字按钮

用于复制、编辑、规则、返回首页。

- 字号 28rpx，颜色 `#B7410E`；次要场景用 `#6F6259`。
- 不设背景；按压时文字透明度 0.7。
- 视觉高度 44rpx，但外层热区补到 88rpx。
- 不带下划线；链接语义靠颜色和位置，不靠下划线。

#### Danger Soft 危险按钮

用于「离开房间」「退出对局」等。

| 状态 | 背景 | 文字 | 描边 |
|---|---|---|---|
| Default | `#FFF0F1` | `#C02C36` | `2rpx solid #F2545B` |
| Pressed | `#FFE3E5` | `#A8222B` | 同 Default |
| Disabled | `#FFF7F7` | `#C9A6A9` | `2rpx solid #F3D6D8` |

- 不使用 `#F2545B` 实底 + 白字（对比度不足）。
- 只在需要明确破坏性确认时使用；普通「离开」可以先用文字按钮，二次确认弹窗再用 Danger Soft。

#### Small 小按钮

用于复制房间码、分享、编辑资料。

- 高度 64rpx，字号 28rpx，左右内边距 24rpx，胶囊圆角。
- 白底 + `#FFD3BF` 描边 + `#B7410E` 文字。
- 视觉 64rpx，但外层包一个 88rpx 高的可点区域。
- 小按钮内可带 28rpx 图标。

#### Icon 图标按钮

- 72×72rpx 圆形，白底，`2rpx solid #F0E4D8`，图标 40rpx。
- 按压：背景 `#FFF0E6`，缩放 0.96。
- 用于返回、关闭、分享；热区补到 88rpx。
- 不在图标按钮里放文字。

### 3.6 按钮状态与交互

| 状态 | 触发 | 视觉 | 行为 |
|---|---|---|---|
| Default | 可操作 | 见各变体 | 点击 |
| Pressed | 手指按下 | 背景加深/下移 2rpx/缩放 0.98 | 120ms 内反馈 |
| Loading | 请求发出 | spinner + 文案，宽度不变 | 禁止再次点击 |
| Disabled | 条件不满足 | 降低对比度，无阴影 | 不触发；旁边给原因 |
| Success | 操作完成 | 不改变按钮，改用 Toast/页面跳转 | 避免按钮闪绿 |

交互细节：

1. 按下即反馈，不等接口返回。
2. Loading 时按钮宽度锁定，避免文字从「创建并邀请」变成「创建中…」导致布局跳动。
3. 同一按钮 600ms 内只响应一次；请求中不响应。
4. 主按钮点击可触发轻振动（受「振动」设置控制）；次按钮不振动。
5. 按钮禁用时**不要**弹 Toast 说「不能点」；在按钮下方或旁边显示原因，例如「再邀请 1 位好友」。
6. 键盘弹起时，底部按钮跟随上移（`adjust-position`），不被遮挡。
7. 不使用 hover 态；小程序以触摸为主。

### 3.7 底部固定操作区

```text
┌──────────────────────────────────┐
│  (渐变，24rpx)                    │
│  ┌────────────────────────────┐  │
│  │         创建并邀请          │  │ 96rpx
│  └────────────────────────────┘  │
│         再邀请 1 位好友           │ 24rpx
└──────────────────────────────────┘
  16rpx + safe-area-inset-bottom
```

| 项 | 规格 |
|---|---|
| 位置 | `position: fixed; left: 0; right: 0; bottom: 0` |
| 背景 | `linear-gradient(180deg, rgba(255,248,240,0), #FFF8F0 24rpx)` |
| 内边距 | `16rpx 32rpx calc(16rpx + env(safe-area-inset-bottom))` |
| 单按钮高度 | 144rpx + 安全区 |
| 带说明高度 | 176rpx + 安全区 |
| 带文字操作高度 | 224rpx + 安全区（如等待页：按钮 + 说明 + 离开） |
| 主按钮 | 宽 686rpx，高 96rpx |
| 说明文字 | 24rpx，`#6F6259`，居中，距按钮 8rpx |

- 页面内容底部预留 180–220rpx，防止最后一行被遮住。
- 底部操作区不放两个主按钮；需要两个操作时，一个 Primary + 一个 Text。
- 结算页的「返回首页/晒战绩」放在主按钮下方一行，字号 28rpx，间距 24rpx。

### 3.8 按钮文案

| 页面 | 按钮 | 文案 | Loading 文案 | 禁用原因示例 |

| 等待（非房主） | Secondary | 邀请好友 | — | — |
| 等待 | Text/Danger | 离开房间 | — | — |
| 对局 | Icon | 返回 | — | — |

### 3.9 按钮禁用与加载的细节

**禁用**

- 背景变浅、文字变灰、阴影移除；不移除布局。
- 按钮下方给出原因（24rpx，`#6F6259`）。
- 禁用按钮仍保留 88rpx 热区，但不触发事件。
- 不要用 `opacity: 0.3` 把整个按钮变得不可读。

**加载**

- spinner 28rpx，2rpx 描边，颜色跟随文字；旋转 800ms/圈。
- 文案切换为「动词 + 中…」，按钮宽度不变。
- 加载中禁止再次点击；请求失败后恢复 Default，并给 Toast/行内错误。
- 加载超过 6 秒仍未返回：按钮恢复可点，提示「网络较慢，再试一次」。

## 6. 关键流程的视觉状态

### 6.1 建房 → 邀请 → 开局

| 步骤 | 页面 | 视觉焦点 | 必须可见的信息 |
|---|---|---|---|
| 1 | 首页 | Primary「创建房间」 | 当前是否有进行中房间 |
| 2 | 创建 | 两组分段选择 + 摘要 | 预计时长、人数上限 |
| 3 | 等待 | 房间码 + 座位 | 人数、谁还没来、能否开始 |
| 4 | 等待 | Primary「开始游戏」 | 人数不足时说明原因 |
| 5 | 对局 | 中央 3-2-1 | 所有人同时进入，题目不可作答 |

关键原则：**等待页的房间码必须是全页最大文字之一**，方便口头报码；开始按钮的状态必须和人数同步。

### 6.2 选项状态机

```mermaid
stateDiagram-v2
    [*] --> Default
    Default --> Pressed: 手指按下
    Pressed --> Selected: 松开，提交请求发出
    Selected --> Submitting: 请求中
    Submitting --> Submitted: 服务端成功
    Submitting --> Selected: 失败且仍可重试
    Submitted --> Correct: 揭晓，答对
    Submitted --> Wrong: 揭晓，答错
    Default --> Disabled: 超时 / 已揭晓 / 他人已答
    Submitted --> Disabled: 揭晓
    Correct --> [*]
    Wrong --> [*]
    Disabled --> [*]
```

- 从 `Selected` 开始，选项不可更改；`Submitting` 只做视觉反馈，不显示「取消」。
- 失败回到 `Selected` 时保留选中态，并给一次轻提示；不要清空用户选择。
- `Disabled` 不等于「灰色不可读」；正确项仍需高亮。

### 6.3 断线 → 恢复

| 状态 | 视觉 | 文案 |
|---|---|---|
| 正常 | 无 | — |

| 恢复中 | 离线条 + 轻 spinner | 正在恢复… |
| 恢复成功 | 离线条淡出 160ms | 已恢复 |
| 房间结束 | 全屏状态 | 房间已结束 |

- 断线时**不清空**当前题目、选项、倒计时；只禁用提交，保留已选。
- 恢复后如果已经进入下一题，直接展示新题；不要补看上一题。
- 倒计时继续按服务端时间走，不因断线暂停。

## 7. 适配与无障碍

### 7.1 屏幕与安全区

- 设计宽度 750rpx；所有尺寸用 rpx，1rpx = 0.5px（375pt）。
- 页面根容器：`min-height: 100vh; padding-bottom: env(safe-area-inset-bottom);`。
- 自定义导航：`padding-top: env(safe-area-inset-top)` 或 JS 读取 `statusBarHeight`。
- 顶部胶囊：右侧预留约 180rpx；自定义导航的右侧不放按钮。
- 底部固定操作区：`bottom: 0; padding-bottom: calc(16rpx + env(safe-area-inset-bottom));`。
- 刘海/灵动岛：Hero、导航、结算领奖台不贴顶；使用安全区 + 24rpx。
- 仅竖屏；不写横屏媒体查询。

### 7.2 小屏适配

| 场景 | 调整 |
|---|---|
| 屏高 < 600pt（iPhone SE 等） | Hero 缩小到 160rpx；题目卡最小 200rpx；选项 104rpx；间距 12rpx |
| 屏宽 320pt | 6 格房间码 88×104rpx，间距 12rpx；按钮左右 24rpx |
| 底部安全区为 0（Android） | 操作区仍保留 16rpx 内边距，不贴边 |
| 大屏（Pro Max） | 内容最大宽度 686rpx，不拉伸卡片；居中 |
| 分屏/小窗 | 允许滚动；不隐藏主按钮 |

### 7.3 长内容

- 题干：最多 3 行；超出内部滚动（P1），底部渐隐 24rpx。
- 选项：最多 2 行；超出省略号；揭晓时可展开（P1）。
- 昵称：最多 8 个汉字显示，超出省略；不换行。
- 房间码：固定 6 位，不换行；字距 8rpx。
- 排行榜昵称：最多 6 个汉字，超出省略；分数右对齐不换行。
- 按钮文字：单行；不接受两行。
- 隐私协议：正常换行，行高 1.7；不做折叠。

### 7.4 字体缩放

- 不写死文字容器高度；用 `min-height` + padding。
- 按钮最小高度 88rpx；字号放大时按钮可增高，不裁切。
- 选项卡片随文字增高；4 张卡片可滚动，不重叠。
- 倒计时环数字放大不超过 40rpx；超出时环随数字放大。
- P1 专项测试：系统字体放大 1.2x/1.5x，页面不重叠、不截断。

### 7.5 对比度与色盲

- 正文对比度 ≥ 4.5:1；大号标题 ≥ 3:1。
- 正确/错误同时使用 ✓/✗ + 文案 + 颜色；不依赖红绿。
- 选项字母徽标保留字母，不只靠颜色区分。
- 倒计时最后 5 秒同时改变数字、环颜色、脉冲；不只变红。
- 房间状态同时有文字 Chip（等待中/对局中/已结束），不只靠颜色。

### 7.6 动效降级

- 尊重系统「减少动态效果」：关闭脉冲、领奖台入场、数字滚动、页面淡入。
- 低端机：倒计时环降级为横向进度条；骨架屏静态；Toast 无淡入。
- 所有动效不超过 400ms；不阻塞点击。

### 7.7 深色模式（P2）

- 首版不做；所有颜色已用 CSS 变量，P2 可通过覆盖变量实现。
- 深色模式需重新验收对比度，不能简单反转。
- 不在首版承诺深色模式，避免审核/体验预期。

### 7.8 无障碍检查

- [ ] 所有可点元素热区 ≥ 88×88rpx。
- [ ] 选项整卡可点，字母徽标不是唯一信息。
- [ ] 正确/错误有 ✓/✗ + 文字。
- [ ] 正文对比度 ≥ 4.5:1。
- [ ] 按钮禁用有原因说明。
- [ ] 倒计时数字与环同步。
- [ ] 字体放大 1.2x 不重叠。
- [ ] 减少动态效果时无脉冲/滚动动画。
